\# Varicose Veins Dataset



\## Overview

This repository contains an Excel dataset for the Edge IoT-Based Diagnosis and Progression Monitoring System for Varicose Veins.



\## Dataset File

\- `Varicosevein \_final dataset.xlsx`



\## Purpose

The dataset is intended for machine learning research, data analysis, and exploratory varicose vein severity classification.



\## Disclaimer

This dataset is intended for research and educational purposes. It is not a substitute for professional medical diagnosis.
